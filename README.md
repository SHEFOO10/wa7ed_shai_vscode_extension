# Wa7ed Shai - Tea Reminder Extension 🍵

A friendly VS Code extension that reminds you to take a tea break by playing a "يكلاني واحد شاي" sound notification.

## ✨ Features

- **Automatic Reminders:** Plays a friendly sound reminder at your preferred interval to encourage you to take a break.
- **Customizable Interval:** Choose how often you want to be reminded (from 30 minutes up to 4 hours).
- **Custom Sound:** Don't like the default? Use your own `.wav` or `.mp3` file.
- **Status Bar Integration:** Quick access button "☕ شاي" in the status bar to trigger the reminder manually.
- **Visual Notifications:** Optional popup messages to accompany the sound.
- **Cross-Platform:** Works on Windows, macOS, and Linux.

## 🚀 Usage

Once installed, the extension activates automatically when you open VS Code.

### Commands

Open the Command Palette (`Ctrl+Shift+P` or `Cmd+Shift+P` on Mac) and search for:

- **`Shai Reminder: Play Sound Now`**: Manual trigger (also available in the status bar).
- **`Shai Reminder: Set Reminder Interval`**: Quickly change the time between reminders.
- **`Shai Reminder: Choose Custom Sound`**: Select your own audio file.
- **`Shai Reminder: Open Settings`**: View and edit all extension configurations.

## ⚙️ Configuration

You can customize the extension in VS Code Settings (`Ctrl+,`):

- `shaiReminder.intervalMinutes`: Minutes between reminders (30 - 240).
- `shaiReminder.showNotifications`: Toggle visual popup messages (default: true).
- `shaiReminder.customSoundPath`: Path to your own audio file.

## 📝 Why This Extension?

Long coding sessions can lead to fatigue and reduced productivity. This extension helps you:

- Stay hydrated and refreshed.
- Take regular breaks from the screen.
- Maintain a healthy routine while coding.
